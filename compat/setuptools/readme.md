# EN

A package for gitversion_simple that adds entry points for setuptools.

Do not install this package directly, but use `gitversion_simple[setuptools]`.

# RU

Пакет для gitversion_simple, добавляющий точки входа для setuptools.

Не устанавливайте этот пакет напрямую, а используйте `gitversion_simple[setuptools]`.
